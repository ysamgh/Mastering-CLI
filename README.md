# 🚀 نقشه راه تسلط بر اوبونتو ۲۲ و گردش کار گیت‌هاب (Mastering CLI)
> این مستند شامل دستورات حیاتی برای مدیریت سرور، تست پروژه‌ها و مشارکت در پروژه‌های متن‌باز است.

---

## ۱. مدیریت سیستم و زیرساخت (Linux Essentials)
*تسلط بر محیط اوبونتو و مدیریت فایل‌ها.*

| دستور | توضیحات |
| :--- | :--- |
| `sudo apt update && sudo apt upgrade -y` | بروزرسانی لیست مخازن و پکیج‌های سیستم |
| `ls -la` | نمایش تمام فایل‌ها (حتی مخفی) با جزئیات |
| `cd ~` | بازگشت به دایرکتوری Home |
| `pwd` | نمایش مسیر دقیق دایرکتوری فعلی |
| `mkdir -p path/to/dir` | ساخت پوشه (به همراه پوشه‌های والد) |
| `rm -rf folder_name` | حذف اجباری و بازگشت‌ناپذیر پوشه و محتویات |
| `cp -r source destination` | کپی کردن دایرکتوری به صورت کامل |
| `mv old_name new_name` | تغییر نام یا جابجایی فایل/پوشه |
| `htop` | نمایش زنده وضعیت منابع سیستم (CPU/RAM) |
| `df -h` | وضعیت فضای خالی دیسک (Human Readable) |
| `free -m` | بررسی وضعیت رم به مگابایت |
| `du -sh *` | نمایش حجم فایل‌ها و پوشه‌های مسیر فعلی |
| `wget [URL]` | دانلود مستقیم فایل از اینترنت |
| `unzip file.zip` | استخراج فایل‌های فشرده |

## ۲. گیت (Git) - مدیریت مخازن و مشارکت
*ابزار اصلی برای تعامل با پروژه‌های GitHub.*

### پیکربندی اولیه
- `git config --global user.name "Your Name"`: تنظیم نام کاربری.
- `git config --global user.email "email@example.com"`: تنظیم ایمیل (مطابق با گیت‌هاب).

### چرخه کاری روزانه (Workflow)
- `git init`: ایجاد یک مخزن جدید در پوشه فعلی.
- `git clone [URL]`: کپی کردن کامل یک پروژه از راه دور.
- `git status`: مشاهده وضعیت تغییرات فایل‌ها.
- `git add .`: اضافه کردن تمام تغییرات به مرحله Stage.
- `git commit -m "Message"`: ثبت نهایی تغییرات در تاریخچه محلی.
- `git push origin branch_name`: ارسال تغییرات به سرور گیت‌هاب.
- `git pull origin branch_name`: دریافت و ادغام آخرین تغییرات از سرور.

### مدیریت شاخه‌ها (Branching & PR)
- `git branch`: لیست شاخه‌های موجود.
- `git checkout -b new_branch`: ساخت شاخه جدید و ورود به آن.
- `git switch branch_name`: جابجایی بین شاخه‌ها.
- `git merge branch_name`: ادغام شاخه مهمان در شاخه فعلی.
- `git remote -v`: مشاهده آدرس مخازن متصل (Origin/Upstream).
- `git fetch --all`: دریافت آخرین اطلاعات تمام شاخه‌ها بدون تغییر در کد.

### ابزارهای عیب‌یابی گیت
- `git log --oneline --graph --all`: نمایش بصری تاریخچه در ترمینال.
- `git stash`: انتقال موقت تغییرات به حافظه پنهان (بدون Commit).
- `git stash pop`: بازگرداندن تغییرات از Stash.
- `git diff`: مشاهده تفاوت‌های خط به خط قبل از ثبت.
- `git reset --hard HEAD~1`: بازگشت به یک کامیت عقب‌تر و حذف تغییرات.

## ۳. داکر (Docker) - اجرای پروژه‌ها در محیط ایزوله
*بهترین راه برای تست پروژه‌ها بدون آسیب به سیستم‌عامل اصلی.*

- `docker ps -a`: لیست کانتینرها (فعال و غیرفعال).
- `docker images`: لیست تمام ایمیج‌های موجود.
- `docker build -t app_name .`: ساخت ایمیج از Dockerfile.
- `docker run -d -p 8080:80 image_name`: اجرا در پس‌زمینه با نگاشت پورت.
- `docker exec -it container_id /bin/bash`: ورود به محیط خط فرمان کانتینر.
- `docker logs -f container_id`: مشاهده زنده لاگ‌ها و خطاهای اجرای پروژه.
- `docker stop $(docker ps -q)`: متوقف کردن تمام کانتینرهای فعال.
- `docker system prune -a`: پاکسازی کامل فایل‌های اضافی داکر (آزاد کردن فضا).
- `docker-compose up -d`: اجرای کل پروژه بر اساس فایل Compose.
- `docker-compose down`: متوقف کردن و حذف تمام سرویس‌های Compose.

## ۴. مدیریت زبان‌ها و پکیج‌ها (Environments)
*راه‌اندازی پیش‌نیازهای پروژه.*

### Python
- `python3 -m venv venv`: ساخت محیط مجازی ایزوله.
- `source venv/bin/activate`: فعال‌سازی محیط مجازی.
- `pip install -r requirements.txt`: نصب تمام کتابخانه‌های پروژه.

### Node.js
- `nvm install --lts`: نصب آخرین نسخه پایدار نود.
- `npm install`: نصب پکیج‌های پروژه.
- `npm start`: اجرای پروژه نود جی‌اس.

## ۵. شبکه و عیب‌یابی (Networking)
*اطمینان از دسترسی به سرویس‌ها.*

- `ufw allow 8080`: باز کردن پورت ۸۰۸۰ در فایروال سیستم.
- `ufw status`: بررسی پورت‌های باز و وضعیت فایروال.
- `netstat -tulpen`: مشاهده تمام پورت‌های در حال شنود (Listen).
- `curl -I localhost:8080`: تست سلامت (Health Check) سرویس داخلی.
- `tail -f /var/log/syslog`: مشاهده زنده گزارش‌های سیستم‌عامل.

## ۶. ویرایشگر متن در ترمینال
- `nano file_name`: ویرایشگر ساده و سریع.
- `vim file_name`: ویرایشگر حرفه‌ای (Esc + :wq برای ذخیره و خروج).
